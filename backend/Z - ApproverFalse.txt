Projects:

Rota POST: http://localhost:3000/projects

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Sem o campo family, um novo projeto é criado.
- O novo projeto é criado com status=1 (rascunho).
- O usuário deve estar vinculado ao team informado.
- Usuários com approver=true no team informado não podem criar projetos.
- A primeira versão recebe version=1.
- O id do próprio projeto passa a ser o family.
- A criação gera automaticamente um log com action="criou".

Rota PATCH: http://localhost:3000/projects/:id

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Apenas o usuário dono do projeto pode editar.
- O usuário deve estar vinculado ao team do projeto.
- Usuários com approver=true no team do projeto não podem editar.

- A edição atualiza last_update.
- A edição gera automaticamente um log com action="editou".

Rota POST: http://localhost:3000/projects

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Quando family é informado, uma nova versão é criada dentro da mesma família.
- A nova versão recebe version = última versão da família + 1.
- A nova versão é criada com status=1 (rascunho).
- O usuário responsável deve ser o mesmo usuário autenticado pelo JWT.
- O usuário deve estar vinculado ao team da família.
- Usuários com approver=true no team da família não podem criar uma nova versão.
- Se a última versão da família estiver com status=1, uma nova versão não pode ser criada.
- A criação da nova versão gera automaticamente um log com action="criou".

Rota GET: http://localhost:3000/projects?parameter=value

parameters: id & name & user & team & family & main_department & related_departments & areas & ods & theme & status & implementation-date & awards & keywords

* related_departments, areas, ods, awards e keywords aceitam vários valores.
* Em arrays, vários valores são pesquisados usando AND (todos os valores devem existir).
* awards e keywords ignoram espaços nas extremidades e diferença entre maiúsculas/minúsculas.
* source retorna as URLs junto com um nome obtido dinamicamente a partir da própria fonte.
* team representa o id do time responsável pelo projeto.
