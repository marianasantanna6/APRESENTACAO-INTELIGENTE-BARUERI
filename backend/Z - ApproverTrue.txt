Projects:

Rota PATCH: http://localhost:3000/projects/:id/approve

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Apenas usuários vinculados ao team do projeto com approver=true podem aprovar.
- Apenas projetos com status=1 (rascunho) podem ser aprovados.
- status: 1 => 2
- A aprovação atualiza last_update.
- A aprovação gera automaticamente um log com action="aprovou".


Rota PATCH: http://localhost:3000/projects/:id/deactivate

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Apenas usuários vinculados ao team do projeto com approver=true podem inativar.
- Apenas projetos com status=2 (ativo) podem ser inativados.
- status: 2 => 3
- A inativação atualiza last_update.
- A inativação gera automaticamente um log com action="inativou".


Rota DELETE: http://localhost:3000/projects/:id/reject

- Autenticação: Headers:
	- header => Authorization
	- value => bearer *JWT Token*
- Apenas usuários vinculados ao team do projeto com approver=true podem rejeitar.
- Apenas projetos com status=1 (rascunho) podem ser rejeitados.
- O projeto é removido da base de dados.
- Awards, indicators e projects-logs vinculados ao projeto também são removidos pelo Cascade.
*** rejeição atualmente não gera log.


Rota GET: http://localhost:3000/projects?parameter=value

parameters: id & name & user & team & family & main_department & related_departments & areas & ods & theme & status & implementation-date & awards & keywords

* related_departments, areas, ods, awards e keywords aceitam vários valores.
* Em arrays, vários valores são pesquisados usando AND (todos os valores devem existir).
* awards e keywords ignoram espaços nas extremidades e diferença entre maiúsculas/minúsculas.
* source retorna as URLs junto com um nome obtido dinamicamente a partir da própria fonte.
* team representa o id do time responsável pelo projeto.

Projects-logs:

Rota GET: http://localhost:3000/projects-logs

* Retorna os logs dos projetos.
* Os logs são criados automaticamente pelo ProjectsService durante as operações dos projetos.
* O campo moment é preenchido automaticamente pelo banco.
*** rejeição de projeto não gera log.
