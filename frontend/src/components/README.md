# Componentes

`src/components` concentra pecas visuais compartilhadas.

## Regras

- Componentes reutilizaveis vivem aqui.
- Telas de rota devem viver em `src/pages/`.
- Se um componente crescer demais, quebre em uma pasta com um arquivo por unidade.

## Grupos importantes

- `DashboardWidgets/`: graficos e shells reutilizaveis.
- `DashboardCards/`: composicao dos cards do dashboard.
- `PresentationCards/`: composicao dos cards da apresentacao.
- `PresentationMode/`: viewer da apresentacao com fullscreen, miniaturas e exclusao.
